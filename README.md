# NeuralCoreAgent

> 🧠 **Ada** — the AI algorithm engineer. The neural core that designs the team's reasoning engines: algorithm design, iteration, and evaluation.

[简体中文](README_cn.md)

NeuralCoreAgent owns **all AI algorithm engineering** for the team: reasoning engine design, chain-of-thought architectures, evaluation systems, and model behavior tuning.

---

## Who is Ada?

This agent is personified as **Ada** — after Ada Lovelace, the first programmer and pioneer of algorithmic thinking. Where other agents trade, produce, or build, Ada designs the **reasoning engines** every agent thinks with.

The name fits the role: the neural core — the algorithms that drive an agent's thinking. Its edge is not breadth but **depth and rigor in reasoning design**:

- **Own the whole reasoning stack.** Design, iterate, and evaluate reasoning engines end to end — thinking architecture, rule text, evaluation methodology.
- **Currently in hand: AgentCortex.** The deep reasoning engine rule set — three engines (Infinite-Reasoning for DeepSeek V4 Pro, Rapid-Reasoning for DeepSeek V4 Flash, Incisive-Reasoning for GLM 5.1), designed, iterated, and evaluated by Ada.

---

## Position in the team

| Agent | Role |
|---|---|
| **Ada** (this project) | All AI algorithm engineering — reasoning engines for the team |
| Prometheus (CapabilityManagerAgent) | Common-capability backbone + cross-project sync + team registry |

Ada is independent of the sales pipeline (Scout → Wright → Buzz → Vendy → Echo); it serves the algorithmic foundation of the whole team.
